# Anti-slop rules

Each rule names its source. `scan.mjs` enforces the rules marked with a scanner id, in the modes shown; the rest need judgment. BAN fails the scan; WARN needs a decision. Curly quotes and apostrophes are normalized before matching. Code, licence files and CLI commands (a tool name followed by arguments with a flag, path or colon) are skipped; prose after a command is still read.

Sources:

- **devsloka**: the `devsloka-anti-slop` skill in [devsloka/ui-devsloka](https://github.com/devsloka/ui-devsloka) (starred), `references/anti-slop.md` and `scripts/slop-scan.mjs`
- **vercel**: [vercel-labs/writing-guidelines](https://github.com/vercel-labs/writing-guidelines) `command.md`, used by the `writing-guidelines` skill in [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) (starred)
- **frontend-design**: the local `frontend-design` skill, sections on generated-design tells and writing
- **brand-review**: the local `marketing:brand-review` skill
- **cqe**: the local `voltagent-biz:content-quality-editor` agent's checklist
- **pocock**: `writing-for-agents` in [mattpocock/skills](https://github.com/mattpocock/skills) (starred), for prompts and skill files
- **tests**: found by blind test runs of this skill
- **research**: [enterprise-messaging.md](enterprise-messaging.md), sources on 2025 and 2026 B2B buyer trust
- **compiled**: common tells in model-written fiction, compiled for this skill; not from the sources above

## Punctuation and glyphs

| Rule                                                                                                                                                                             | Source              | Scanner                                                     |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ----------------------------------------------------------- |
| No dash as punctuation (`—`, spaced `–`, spaced `--`). Use a period, comma, colon or parentheses. In fiction, a dash before a closing quote marks cut-off speech and is allowed. | vercel, cqe         | `em-dash` BAN                                               |
| No emoji in copy, headings or as icons. Use words or a real icon.                                                                                                                | devsloka            | `emoji` BAN (marketing, creative); `emoji-docs` WARN (docs) |
| No arrow appended to links or buttons (`→`, `->`).                                                                                                                               | frontend-design     | `arrow-glyph` BAN (marketing)                               |
| No meta strings joined with middle dots (`A · B · C`).                                                                                                                           | frontend-design     | `middle-dot-meta` WARN (marketing)                          |
| One exclamation mark at most, and rarely. In fiction only stacked marks (`!!`) are flagged; `"Run! Now!"` is dialogue.                                                           | brand-review, tests | `exclamation-stack` WARN                                    |
| Ellipsis is one character (`…`), not three periods.                                                                                                                              | vercel              | `three-dots` WARN (docs)                                    |
| No Markdown in plain-text posts (bold, italics, headings, list markers, backticks).                                                                                              | tests               | `markdown-in-plain-text` BAN (with `--channel social`)      |
| Curly quotes and non-breaking spaces in units (`64 KB`) on web pages, documents and captions. Plain-text posts may keep straight quotes.                                         | vercel, tests       | judgment                                                    |
| No bold or italics for tone. Bold only for UI labels or a critical fact.                                                                                                         | vercel              | judgment                                                    |

## Assistant voice, hedging and structure

| Rule                                                                                                                                                                               | Source          | Scanner                                              |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- | ---------------------------------------------------- |
| No assistant openers or closers (`Great question`, `Certainly`, `Of course`, `Absolutely`, `I hope this helps`). In fiction these are ordinary narration.                          | cqe             | `sycophant-opener` BAN (marketing, docs)             |
| No hedging stacks (`it's worth noting`, `it is important to note`, `it should be noted`, `needless to say`). A character may hedge in dialogue.                                    | cqe             | `hedge-stack` BAN (marketing, docs), WARN (creative) |
| No hedging phrases (`at the end of the day`, `when it comes to`).                                                                                                                  | cqe             | `hedge-phrase` BAN (marketing, docs)                 |
| No filler transitions opening a sentence (`Furthermore,`, `Moreover,`, `Additionally,`, `In conclusion,`, `Ultimately,`, `In summary,`, `That said,`, `Notably,`, `Importantly,`). | cqe, compiled   | `filler-transition` WARN (marketing, docs)           |
| Don't restate an earlier sentence in new words, at a paragraph's start or anywhere else.                                                                                           | vercel, tests   | judgment                                             |
| Don't chop one idea into fragments for drama (`Fast. Simple. Yours.`).                                                                                                             | vercel          | `fragment-run` WARN (marketing)                      |
| Sentences under about 20 words in marketing and docs.                                                                                                                              | vercel          | `long-sentence` WARN over 25 words (marketing, docs) |
| Vary sentence length: no three sentences in a row within two words of the same length, inside one paragraph.                                                                       | compiled, tests | `rhythm-run` WARN (with `--rhythm`)                  |
| Describe what you want rather than what to avoid, in prompts and skill files.                                                                                                      | pocock          | judgment                                             |

## Product marketing

| Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Source                        | Scanner                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | ------------------------------------------------- |
| Banned hype: `unlock`, `unleash`, `supercharge`, `revolutionize`, `seamless`, `effortless`, `elevate`, `empower`, `game-changer`, `game-changing`, `cutting-edge`, `next-level`, `leverage`, `harness the power`, `in today's fast-paced`, `transform your`, `all-in-one`, `streamline`, `world-class`, `best-in-class`, `robust`, `powerful yet simple`, `built for the future`, `your journey`, `say goodbye to`, `look no further`, `like never before`, `at your fingertips`, `reimagine` | devsloka                      | `hype-phrase` BAN (marketing, docs)               |
| Also banned: `delve`, `utilize`, `synergy`, `paradigm shift`, `state-of-the-art`, `future-proof`, `one-stop shop`, `mission-critical`, `deep dive`, `unparalleled`, `groundbreaking`, `innovative solution`, `holistic`                                                                                                                                                                                                                                                                       | cqe, compiled                 | `hype-phrase` BAN (marketing, docs)               |
| No placeholder people or text (`lorem ipsum`, `John Doe`).                                                                                                                                                                                                                                                                                                                                                                                                                                    | devsloka                      | `hype-phrase` BAN                                 |
| Superlatives (`the best`, `fastest`, `#1`, `the only platform`) need a number and a source.                                                                                                                                                                                                                                                                                                                                                                                                   | brand-review                  | `superlative-claim` WARN (marketing)              |
| CTAs name the action and object (`Deploy Data Viewer`), not `Get started`, `Learn more` or `Discover what…`.                                                                                                                                                                                                                                                                                                                                                                                  | devsloka, vercel              | `weak-cta` WARN (marketing)                       |
| Don't open a post with a question. Open with the incident or what the thing does.                                                                                                                                                                                                                                                                                                                                                                                                             | research                      | `question-hook` WARN (marketing, first line only) |
| Run the structural review in `enterprise-messaging.md`: no generic setup, invented audience, competitor positioning, noun stacks, defensive disclaimer or repeated devices.                                                                                                                                                                                                                                                                                                                   | research                      | judgment (step 5)                                 |
| Don't open with a template label (`Introducing`, `Meet`, `Say hello to`) or a tracked all-caps eyebrow.                                                                                                                                                                                                                                                                                                                                                                                       | frontend-design, devsloka     | `introducing-label` WARN (marketing)              |
| No `not just X, but Y`, `It's not X. It's Y.` or `It wasn't X. It was Y.` contrasts.                                                                                                                                                                                                                                                                                                                                                                                                          | compiled                      | `not-just-x` WARN (marketing, creative)           |
| No rhetorical-question hooks (`Ever wondered`, `Tired of`, `What if`, `Imagine`). A concrete question in the reader's nouns is fine.                                                                                                                                                                                                                                                                                                                                                          | vercel, tests                 | `rhetorical-q` WARN (marketing, docs)             |
| Replace effort words (`easy`, `simple`, `just`, `quick`, `very`, `really`, `finally`) with the concrete thing.                                                                                                                                                                                                                                                                                                                                                                                | vercel                        | `filler-word` WARN (marketing, docs)              |
| Replace vague quantities (`many`, `often`, `significantly`, `lightning-fast`, `near-zero`) with a figure. The question `how many` is fine.                                                                                                                                                                                                                                                                                                                                                    | vercel, tests                 | `weasel-word` WARN (marketing, docs)              |
| Replace datasheet verbs (`provides`, `allows you to`, `is designed to`) with what the reader does or gets.                                                                                                                                                                                                                                                                                                                                                                                    | vercel                        | `datasheet-verb` WARN (marketing, docs)           |
| Logo-swap test, for headlines that make a claim about the product: if a competitor's name fits, rewrite with the least-shared fact you hold, or report it as generic. A headline that states the reader's problem is exempt.                                                                                                                                                                                                                                                                  | devsloka, tests               | judgment                                          |
| Highlight one word in a headline only as a rationed device (2 to 3 times per video or page).                                                                                                                                                                                                                                                                                                                                                                                                  | frontend-design               | launch-video `lint`                               |
| Never invent social proof, customer logos, review counts, metrics or calls to action.                                                                                                                                                                                                                                                                                                                                                                                                         | devsloka, brand-review, tests | launch-video `lint` (stats); judgment             |

## Creative writing

These come from the "compiled" and "tests" sources. Multi-word stock phrasing is a BAN, because it is almost never literal. Words with ordinary literal uses are a WARN: keep one only when it is literal (a woven tapestry, a palpable mass in a medical exam, the smell of ozone after lightning) and say so in the report. Marketing vocabulary is not checked in this mode, so `She unlocked the cage` passes.

| Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Scanner                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| Stock phrases: `testament to`, `a dance of`, `little did <anyone> know`, `unbeknownst to`, `a breath she didn't know she was holding` (and `didn't realize she'd been holding her breath`), `shivers or a chill down her spine`, `ministrations`, `the weight of it all`, `something inside her shifted`, `time stood still`, `eyes sparkled`, `a smile tugged at`, `unspoken understanding`, `the air was thick with`, `barely above a whisper`, `barely audible`, `echoes of the past`, `whispers of the past`, `a pang of`, `knuckles white`, `would change everything`, `would alter the course of`, `nothing would ever be the same`, `forgotten memories`, `the silence was deafening`, `the silence was a living thing`, `silence stretched`, `a wave of <feeling> washed over`, `fear gripped`, `dread pooled`, `her heart was pounding`, `her heart hammered against her ribs`, `her breath hitched`, `a muscle ticked in his jaw`, `somewhere in the distance, a dog barked`, `some doors are meant to stay closed` | `fiction-cliche` BAN       |
| Loaded words with literal uses: `tapestry`, `symphony of`, `in the heart of`, `palpable`, `something shifted`, `eyes glinted`, `the smell of … ozone`, `let out a (long) breath`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | `fiction-cliche-word` WARN |
| Default names (`Elara`, `Kael`, `Lyra`, `Seraphina`, `Thorne`, `Eldoria`, `Mara Chen`, `Kira Voss`, `Sable`, `Zephyr`), matched with their capital letter only, so `sable brushes` passes. Choose a name with a reason (era, region, family).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `fiction-names` WARN       |
| Reflex similes (`it was as if`, `couldn't help but`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `as-if-simile` WARN        |
| No moral or summary ending (`In the end,`, `And in that moment`, `Perhaps that was enough`). Checked on the last line only; mid-story uses are ordinary narration. End on an image or an action.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | `moral-ending` WARN        |
| Show feeling through action and detail, not named emotion (`she felt afraid`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | judgment                   |
| Dialogue tags are `said` and `asked`; let the line carry the tone.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | judgment                   |
| No italics for emphasis or inner voice unless the piece establishes a convention for it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | judgment                   |

## Docs

| Rule                                                                          | Source | Scanner         |
| ----------------------------------------------------------------------------- | ------ | --------------- |
| Address the reader as `you`, not `the user` or `one`.                         | vercel | `the-user` WARN |
| Sentence case for headings; no single generic headings (`Overview`, `Notes`). | vercel | judgment        |
| Active voice, present tense, paragraphs of 2 to 4 sentences.                  | vercel | judgment        |
| Anchor text names the destination; never `here` or a bare URL.                | vercel | judgment        |
